### 逐题分析

**1. ✅** 结论是专家的否定判断「多吃黑芝麻不能有效预防白发」，削弱要找「它其实能预防」的机制。D 给出铜元素、花青素激活酪氨酸酶、参与黑色素合成进而维持发色，正面顶回去。A（黑色素被消化分解）、B（日常摄入已够）、C（有效成分有限且脂肪高）都在替专家说话；E 只讲黑芝麻之外的影响因素。选 D 稳。

**2. ❌** 论证结构：灭绝与火灾正相关 → 灭绝是火灾的原因。要断因果，最狠的是共同他因：A 说两者都是气候变化的结果，一刀把相关解释掉。你选的 C 是「火灾频发导致捕猎者系统崩溃」——这是火灾的下游后果，跟「灭绝→火灾」这条链没有接触面，放在哪里都不构成削弱。D 是支持（灭绝→易燃植物→过火面积更大），E 只有「可能」且没排除题干因果。

　　→ 错因：模型选错。选了无关项（火灾→捕猎者崩溃），没打在「灭绝→火灾」的因果上。

**3. ✅** 解释链是：出汗散热 + 可自由调节呼吸 → 能按猎物不适应的速度追到力竭 → 长跑耐力有演化优势。C 说狩猎主要靠偷偷靠近、围圈捕捉，直接抽掉「靠长距离追猎」这个前提，解释随之落空。A 说人类专挑不擅长长跑的动物，反是支持；E 讲今天不追猎，与「当初为何演化出」无关。

**4. ✅** 证据链：陨石富含钇 → 撞击升起富钇尘云 → 落回地表混入新沉积层 → 富钇岩层。要反对「钇层 = 陨石证据」，最有效是指出别的来源：D 说 6000 万年前剧烈火山喷发也形成巨大富钇尘云，替代来源成立。B 只讲硬化耗时长短，不否定钇从哪来；E 是恐龙灭绝那条线，与钇无关。

**5. ✅** 目标是「早期发现很少刷牙者的口腔癌」，手段是发小册子教每周自检。削弱方法要落在「手段—目标人群」的错配上：E 说很少刷牙的人不大可能每周自检，等于说这册子到不了真正需要的人手里。D（自检不如医院检查）看着有道理，但这群人本来就不就医，削弱力度弱一档；A 只说「有些」病征，范围太窄。

**6. ✅** 学者结论：商业模式难长久；理由是核心吸引力在宁静与原生性，大规模商业化会破坏它。C 给出第三条路——科学规划 + 社区共建，完善配套的同时保留风貌，直接否掉「商业化必然破坏」这个中间环节。A 是参与者画像，B/D/E 都在给「难长久」添砖，全是加强。

**7. ✅** 结论靠类比：鼠的 Teneurin-4 变异 → 无髓鞘 → 神经短路 → 震颤，所以人类同理。类比的命门是「人身上有没有同一个机制」。E 说人类体内没有这种基因，前提直接不存在。A（同类基因受抑制也髓鞘不全）、B（人类致病基因与鼠类似）都在加强；D「症状不完全相同」太弱，症状不同不妨碍机制相同。

**8. ✅** 论据是「喜欢京剧的占 14%」，结论是「大学生普遍缺乏传统文化积累」。中间偷换了概念：京剧只是传统文化的一个小切面。B 点破「喜欢京剧≠学习传统文化，不要以偏概全」，正好打在桥断处。A 是替「不喜欢」找理由，属于加强；E 质疑样本，但 14% 是比例不是样本量，也没给出替代数据。

**9. ❌** 论据是「上班第一天在一处看到自由散漫」，结论是「管理失效，员工都缺乏积极性和责任心」。从一天、一处推到 2 万人、十多个城市，缺口是样本代表性。B 把总体的规模摆出来，正好戳这个缺口。C 说莫大伟刚毕业不适应社会，是攻击观察者本人，不触及论证结构，而且题干没有任何依据支持；E 只能解释当天为何异常，压不倒「都缺乏」这个全称结论。

　　→ 错因：模型选错。用「观察者不适应社会」代替样本问题，攻击人身而非论证结构。

**10. ✅** 论证的隐含前提是「狮子桥这片建筑都是违法建筑」，配上「凡违法建筑均应拆除」才推得出「均应拆除」。E 说其中有些不是违法建筑，直接否掉小前提，结论就塌了。C 说都有经营许可证——有证不等于建筑合法（许可经营与规划合法性是两码事）；D 说有些未获批准，反而更像在支持「违法」。

**11. ✅** 规定是「只有成绩优秀并且品德优良，才能被评为优秀学生干部」，即：评优干 → 成绩优秀 ∧ 品德优良。张三只坐实了成绩这一半，还差品德。E 说品德有问题，必要条件缺一个，结论不成立。A、B 讲班长工作做得好不好，那不是评选的构成条件；C、D 与条件无关。

**12. ✅** 调查给出的是相关：起居不同 ↔ 争吵更多；结论却要求「改起居能减少争吵」，这就把相关当成了因果。B 给出反方向：是闹矛盾之后，一方故意用不同时起居表示不满——因果倒置，相关性照旧成立但干预无效。E 说「很少是直接原因」只是把因果说弱，没有解释相关从哪来，力度不如 B。

**13. ❌** 结论把两组差异归因于「复杂环境与动物之间的互动」。要削弱，得指出肿瘤缩小另有机制。D 给出替代原因：复杂环境鼠肾上腺素水平升高，而肾上腺素本身抑制肿瘤生长——功劳不必记在「互动」头上。你选的 E（普通环境鼠体质更差）是笼统的体质差异，而且「体质」很可能就是环境造成的结果，没有独立机制，说不清方向；B 说复杂环境鼠面临更多纷争挑战，方向反而与「互动有益」相冲突。旁注「样本问题」方向对了一半——本题的缺口不是样本量，而是归因。

　　→ 错因：模型选错。用笼统的「体质差异」代替具体替代机制，且未针对被归因的「互动」。

**14. ✅** 队列数据是：久坐时间越长，18 岁抑郁评分越高。相关要被解释成「久坐→抑郁」，得排除共同原因。A 说这些久坐的青少年大多沉迷恐怖类游戏、精神受影响——游戏既导致久坐又导致抑郁，共同他因，链条断掉。E 只解释「为什么久坐」（课业负担），没有接到抑郁上；B 讲另一群人的抑郁来源，与久坐者不重叠；C、D 方向都不对。

**15. ❌** 论据是「填埋垃圾中塑料占比上升」，结论是「代用品的努力几乎没有成效」。这里藏着一个分母陷阱：占比上升不等于塑料绝对量增加。A 说垃圾分类后大量原本填埋的垃圾被回收，填埋总量缩小，塑料占比自然被推高，而塑料本身可能已经减少。你选的 E（塑料只适合填埋）恰恰是在加强「塑料只能进填埋场」，方向反了；B、C 也在加强，D 只是质疑统计范围。

　　→ 错因：模型选错。把加强项当削弱项，未识别「占比上升≠总量增加」的分母效应。

### 错因归纳

四道错题分两类，根子是同一个动作没做：

- **削弱方向选偏（2、9、13）**：都在「外围」找质疑点——2 挑了火灾的下游后果，9 挑了观察者本人，13 挑了笼统的体质差异。三题的正确答案（A、B、D）都直接落在「论据 → 结论」那一步上：共同他因、样本代表性、替代机制。
- **选项方向判反（15）**：E「塑料只适合填埋」明明是加强项，被当成削弱选了；同时没看出「占比上升」是分母缩小造成的。
- 共性：没有先把「结论 / 论据 / 缺口」写成一句话，凭选项语感选「读起来像在质疑」的那条。
