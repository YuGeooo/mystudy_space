## Q19
(a + b + c)^2 = a^2 + b^2 + c^2 + 2ab + 2ac + 2bc

( |a| + |b| + |c| ) ^2 =  a^2 + b^2 + c^2 + 2|ab| + 2|ac| + 2|bc|


a^2 + b^2 + c^2 
= (a + b + c)^2 - 2 (ab + ac + bc)
= (a + b + c)^2 - 2 (|ab| + |ac| + |bc|)

case 1 :
|a| + |b| + |c| <= 1 
--->,  (|a| + |b| + |c|) ^2 <= 1 
--->,  a^2 + b^2 + c^2 + 2|ab| + 2|ac| + 2|bc| <= 1
--->, a^2 + b^2 + c^2 + <= 1 - 2 (|ab| + |ac| + |bc|) 
case1 单独成立

case2:
ab + bc + ac = 0
---> a^2 + b^2 + c^2 = (a + b + c)^2 
要证明 a^2 + b^2 + c^2 <=1
可以同等证明 (a + b + c)^2 <=1
即 |a+b+c| <= 1
反例：a=4, b=0, c=0
case2 单独不成立

### Answer : A ✅

### 批改：
答案正确，但推理中有一处不能直接写：
$$
ab+ac+bc=|ab|+|ac|+|bc|
$$
这个等式只在 $ab,ac,bc$ 同号或为零时成立，条件(2)下并不恒成立。

条件(1)的严格推导应为：
$$
a^2+b^2+c^2\le a^2+b^2+c^2+2(|ab|+|ac|+|bc|)
=(|a|+|b|+|c|)^2\le1.
$$
条件(2)单独不充分，反例 $a=4,b=0,c=0$，此时 $ab+bc+ca=0$，但 $a^2+b^2+c^2=16>1$。
所以选 **A**。

## Q20

f(x) = |x-a| - |x-1| <= 1

由几何意义，绘图，需要满足 0 <= a <= 2 才成立

### Answer : C ✅

### 批改：
答案正确，但建议把“由几何意义”补成严格推导：
$$
f(x)=|x-a|-|x-1|\le |(x-a)-(x-1)|=|a-1|.
$$
所以当 $0\le a\le2$ 时，$|a-1|\le1$，对任意实数 $x$，都有 $f(x)\le1$，联合充分。

单独条件不充分：
- (1) 取 $a=3$，$x=0$，则 $f(0)=3-1=2>1$；
- (2) 取 $a=-1$，$x=1$，则 $f(1)=2-0=2>1$。

故条件(1)(2)单独不充分，联合充分，选 **C**。
