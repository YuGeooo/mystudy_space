# 题库

真题与专项练习的本地副本：题干、作答与批改、答案速查、各卷总结。截至 2026-11-12 共 60 份 Markdown。

| 文件 | 是什么 |
|---|---|
| `paper.md` / `形式逻辑与综合推理一.md` / `应用题.md` | 题干，公式用 LaTeX |
| `answer*.md` | 一次或一批的作答与批改：判定表 → 逐题分析 → 错因归纳 |
| `答案速查.md` | 该卷客观题答案 |
| `批改总结.md` / `试卷总结.md` / `全书总结.md` | 阶段性总结 |
| `生词本.md` | 英语阅读与翻译的生词 |

## 怎么用

- **翻题、找错因**：直接读文件，或者 `grep -rn "倍数搞错" 题库/` 这种跨卷检索——这是本地副本最大的用处。
- **以云端库为准**：题干、判定、错因的权威值在库里，`mem q get <id>` / `mem s get <id> --process` 取到的就是当前的。
- **新的记录不写在这里**：一场练习用 `mem s new` 进库，新总结写 `../总结/`。本地文件是"回看用的副本"，不是录入入口。
