# 错因标签口径

`attempts.error_tag` 怎么取值：词表、字段写法、当前覆盖。数字一律从云端库取（`mem sql`），
补了标签或改了批改就同步更新这份文档——它是口径，不是历史记录。

## 字段写法

- `errorTag`：主错因，单值，取下面 16 个之一 —— 统计用它 `group by`。
- `errorTags`：一题多毛病时给数组，第一个元素与 `errorTag` 相同（目前 1 条：`2020-exam-q019`，模型选错 + 算术笔误）。
- 具体错在哪一步仍看 `process_md` 正文，标签只做归类，不替代批改。

## 词表

### 数学（六类）

| 标签 | 判定要点 |
|---|---|
| 模型选错 | 解题模型或公式选错、记错；削弱/加强题里削弱角度选错也归此类 |
| 约束遗漏 | 漏掉题干给定的范围、存在性、整数要求、限定语（如「正整数」「小学生」） |
| 倍数搞错 | 排列组合漏乘或多除阶乘；按倍数/比例分配时漏掉一组 |
| 移项·符号 | 移项、去分母、负号、符号区间方向出错 |
| 算术笔误 | 模型与步骤都对，纯数值算错 |
| 书写跳步 | 中间步骤没落纸，导致最后落选项时对不上、或复查不可追溯 |

### 逻辑（六类）

| 标签 | 判定要点 |
|---|---|
| 条件翻译方向 | 「只有…才」「只要…就」「除非…否则」「只在…生活」的充分/必要方向译反，含否定前件、肯定后件 |
| 等价转换 | 否定式、逆否、德摩根没做到底或方向错（¬(A∧B∧C) 收窄成单支否定等） |
| 量词·模态 | 全称/特称、可能/必然的对当关系错；「可能 P ⟺ 不必然 ¬P」 |
| 定义要点 | 概念定义的核心要素抓错（如把言行不一当成 NIMBY） |
| 搭桥缺失 | 加强/削弱/假设题没找到「论据 → 结论」之间的那一环 |
| 审题 | 看反题干要求（「除了」「不支持」看成「支持」）、抄错题干条件、把「可采用」读成「需要」 |

### 英语（三类）

| 标签 | 判定要点 |
|---|---|
| 词义·搭配 | 完形/词汇题词义辨析或固定搭配错 |
| 细节定位 | 阅读细节题定位错、把局部当核心、与原文表述相反 |
| 主旨概括 | 段落主旨或小标题概括偏，只抓一方立场 |

### 通用（一类）

| 标签 | 判定要点 |
|---|---|
| 未作答 | 草稿标 Pass 或留空，按未作答计错 |

## 口径说明

1. 标签取自批改正文的原始判断，不重新判题、不改 `correct`。正文写得含糊的（2024-exam 9 月那批批改极简）
   按「错在最后一步是什么动作」归类，已知偏主观，日后有异议用 `mem a set <id> errorTag=...` 覆盖。
2. 只标错题。`correct=1` 但过程有跳步的不标（`substantiveCorrect` 仍为 null，另案处理）。
3. 未判定的 7 条主观题不标，等判分后再看要不要标。
4. 新标签只从上面 16 个标准词里选，不临时造词；确实归不进去的，先改这份口径再加词。
5. 补标签用 `mem a set <id> errorTag=...`，一次一条；补完回填「当前覆盖」里的数字。
