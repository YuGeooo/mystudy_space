# 总结

一场或一卷结束后写在这里，**只在末尾追加并注明日期**，不改历史段落。

| 文件 | 内容 |
|---|---|
| `管综-批改总结.md` | 管综各卷：逐场要点、错因归纳、下一步题号区间 |
| `英语二-试卷总结.md` | 英语二：分题型得分、失分原因、复习重点 |
| `生词本.md` | 阅读/翻译里的生词，按出现顺序追加 |

三条约定：

1. 数字要能追溯——题目数、正确率、时长都取自云端库（`mem p get <slug>` / `mem s get <id>`），不凭记忆。
2. 统计口径写在文件开头（首做 / 含订正 / 是否计时），批改更新后同步修订口径说明。
3. 各卷既有的总结在 `../题库/<卷名>/` 下（`批改总结.md` / `试卷总结.md` / `生词本.md`），翻看用；新的追加只写本目录，不要改那边。

数据结构、错因标签与字段含义见 [`../AGENTS.md`](../AGENTS.md)。
